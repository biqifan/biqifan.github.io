掌阅
2.1 2026.07—2026.09

掌阅科技股份有限公司

商业化运营 / 用户运营实习生

数字阅读 · 广告变现

负责范围对接华为 / vivo / OPPO 及穿山甲、优量汇等广告联盟，跟进从请求到留存的转化漏斗，对 CTR、eCPM、填充率等核心指标负责。

关键动作

  • 全链路运营理解 DSP→ADX→SSP 链路，覆盖请求 → 展示 → 点击 → 下载 → 激活 → 留存全漏斗。
  • 指标归因每日跟踪 CTR / eCPM / 填充率，建立流量侧、广告侧、平台侧三维归因法，定位 DAU 流量结构与渠道预算异常并推动恢复。
  • 增长测试主导 OPPO 渠道 PUSH A/B 测试，合并低效人群包、优化文案，形成触达—回收—调优闭环。
  • 资料沉淀配置福利页与福利卡促活，梳理 PUSH 全流程 SOP 并输出周度报表。

量化结果

  • 25%PUSH 点击率，由 20% 提升（+5pct）
  • 12个节点的 PUSH 全流程 SOP
  • 2 天新人上手周期，原为 1 周
  • 30+份累计输出报表
闪送
2.2 2026.11—至今

北京同城必应科技有限公司（闪送）

渠道运营实习生

即时配送 · 渠道增长

负责范围负责主流应用商店渠道效果监测与外部合作渠道的全链路配置，用数据驱动渠道拉新与用户促活，并跨设计、法务、财务推进合作落地。

关键动作

  • 渠道运营与增长主导华为 / OPPO / 小米 / vivo / 荣耀应用商店效果监测，跟踪自然搜索与竞品词排名，推动品牌词在搜索场景优先露出，直接驱动渠道拉新。
  • 渠道配置与促活独立完成广告位排期、专属券码创建、API 接口对接与 H5 落地页上线，同步推进功能与页面类需求的提报及验收。
  • 跨部门协同向设计输出素材需求，协同法务完成合同审核、对接财务处理发票对账，联动合作方统筹线上线下物料。
  • 数据驱动用 SQL 提取业务数据，依托内部 BI 平台完成渠道监控与效果复盘，输出优化方案并推动落地。

量化结果

  • 5 家主流应用商店渠道并行监测
  • 全链路渠道配置独立完成并上线
  • SQL+BI日常取数与渠道复盘
  • 线下参展拓客与异业合作拓展
